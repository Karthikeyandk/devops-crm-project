# DevOps CRM Project - Local Setup and Automation

## 1. Project Overview

This project is a Twenty CRM application developed using the Twenty application SDK.

The objective of this task was to:

1. Clone and explore the project repository.
2. Set up and run the application locally.
3. Create a Python script to automate the local setup and startup process.
4. Document the setup process, automation, issues faced, and their solutions.
5. Create a separate Git branch and push the changes to a personal fork.
6. Raise a pull request without creating the PR directly in the official repository.

## 3. Prerequisites

The following tools were required to run the project locally:

- Windows
- Git
- Node.js
- Yarn 4
- Docker Desktop
- MSYS2 UCRT64
- Python 3

The environment used for this task included:

- Node.js 24.14.1
- Yarn 4.13.0
